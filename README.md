# 🚀 Reel Reach - Premium Instagram Course Landing Page

A high-conversion, cinematic landing page designed for the **Veeru Vajrawad Instagram Course**. This platform features a premium aesthetic, buttery-smooth animations, and a mobile-first "gallery-style" curriculum explorer.

![Reel Reach Preview](https://github.com/suleshcreates/reel_reach/raw/main/public/preview.png) *(Note: Add a screenshot later)*

## ✨ Key Features

- **💎 Premium Design**: Sleek dark/light mode aesthetics with glassmorphism and animated background orbs.
- **🚀 Ultra-Smooth Scrolling**: Powered by **Lenis** for an effortless, inertial scrolling experience.
- **📱 Mobile-First Slider**: Tactile, horizontal "gallery-style" curriculum explorer for mobile users.
- **📈 Growth-Focused**: Integrated WhatsApp community "Success Wall" with real student wins.
- **⚡ Performance Optimized**: Built with **Vite + React** for lightning-fast load times.
- **🎭 Cinematic Reveals**: Staggered scroll animations for a premium storytelling feel.

## 🛠️ Tech Stack

- **Core**: React 18, Vite
- **Styling**: Vanilla CSS (Scoped)
- **Animations**: CSS Transitions, Scroll-Reveal, Lenis Smooth Scroll
- **Deployment**: GitHub Pages

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/suleshcreates/reel_reach.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run locally:
   ```bash
   npm run dev
   ```

## 📦 Deployment
The project is configured for automated deployment via GitHub Pages.

To deploy manually:
```bash
npm run deploy
```
